# GAIA v0.10 Acceptance Criteria

GAIA v0.10 is complete only when all of the following are true:

- canonical Project Contract exists;
- Architecture Registry exists;
- cross-project dependencies are deterministic;
- dependency cycles are detectable;
- reverse dependencies are queryable;
- change impact is explainable;
- unknown impact remains unknown;
- programme roadmap is deterministic;
- release-train sequencing is explainable;
- Programme Packages are revisioned;
- approval never executes work;
- Programme Packages can group multiple project work packages;
- provenance is preserved;
- stale evidence remains visible;
- Windows Programme workspace is operational;
- API, CLI, and client expose supported functionality;
- Dashboard programme surface is read only;
- v0.9 compatibility remains preserved;
- MicroGrow remains read only;
- no automatic Codex;
- no external repository mutation.

## Acceptance Test Rule

Acceptance is not subjective. Each bullet must be supported by deterministic records, validation output, or repeatable tests.
