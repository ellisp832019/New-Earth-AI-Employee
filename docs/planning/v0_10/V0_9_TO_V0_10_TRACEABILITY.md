# v0.9 to v0.10 Traceability

## Continuity Map

- v0.9 project registry -> v0.10 project contract;
- v0.9 change intelligence -> v0.10 change-impact engine;
- v0.9 recommendation ranking -> v0.10 programme roadmap;
- v0.9 work packages -> v0.10 programme packages;
- v0.9 Windows Project Officer workspace -> v0.10 Windows Programme Intelligence workspace;
- v0.9 Dashboard summary -> v0.10 programme summary views;
- v0.9 provenance and handoff -> v0.10 decision and provenance model;
- v0.9 API and client compatibility -> v0.10 preserved integration boundary.

## Design Principle

v0.10 should extend the released v0.9 concepts instead of replacing them. The v0.9 release is the frozen baseline for all compatibility decisions.
