# Windows Programme Workspace Plan

## Objective

Add a v0.10 programme intelligence workspace inside the existing GAIA Windows Control Centre. Do not create a second application.

## Planned Surfaces

- Programme Overview;
- Architecture Registry;
- Dependency Graph;
- Impact Analysis;
- Change Proposals;
- Programme Roadmap;
- Release Trains;
- Programme Packages;
- Decisions;
- Cross-Project Evidence.

## Interaction Rule

The workspace is for review, not execution. There should be no automatic action buttons, no external repository operations, and no approval authority that bypasses human review.

## Rendering Rule

Flutter should render canonical backend data only. Graph layout, impact results, and readiness states are backend-owned.
