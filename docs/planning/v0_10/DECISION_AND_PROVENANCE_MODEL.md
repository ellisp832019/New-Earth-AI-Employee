# Decision and Provenance Model

## Purpose

GAIA v0.10 must make programme reasoning auditable. Every high-level claim should be traceable to source evidence, a revisioned record, or a derived graph snapshot.

## Decision Record

Link decisions to:

- reason;
- alternatives;
- constraints;
- affected projects;
- affected architecture;
- date;
- evidence;
- superseding decision.

## Provenance Records

Trace evidence for:

- project snapshot;
- repository SHA;
- project contract revision;
- architecture entity revision;
- architecture relationship revision;
- recommendation;
- work package;
- change proposal;
- programme package;
- decision record;
- validation evidence;
- release evidence.

## Rule

No unexplained programme verdicts. If provenance is missing or stale, say so.
