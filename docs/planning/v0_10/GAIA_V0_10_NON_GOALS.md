# GAIA v0.10 Non-Goals

GAIA v0.10 does not attempt to:

- autonomously execute software development work;
- run Codex or other agents automatically;
- execute arbitrary shell commands on demand;
- mutate external repositories;
- create external branches;
- automatically merge or deploy releases;
- expand into hardware control;
- move to a cloud-first architecture;
- require telemetry;
- download models automatically;
- replace human engineering judgement;
- grant the Dashboard approval authority;
- create a competing project registry.
