# GAIA v0.9 API and Capability Plan

## API Goals

- expose project-health snapshots;
- expose drift and change findings;
- expose ranked recommendations;
- expose work queues and work packages;
- expose approval and handoff records;
- expose completion evidence.

## Capability Goals

- portfolio intelligence;
- change intelligence;
- recommendation intelligence;
- work-package preparation;
- human-review workflow;
- read-only Dashboard summaries.

## Compatibility Rules

- preserve backward compatibility with released v0.8 clients where practical;
- do not force an immediate Dashboard update;
- version any new API surfaces explicitly;
- keep capability discovery deterministic and readable.
