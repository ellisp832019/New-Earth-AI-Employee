# GAIA v0.9 Start Here

GAIA v0.9 is the planning and architecture milestone for a practical local-first project officer.

## Baseline

- GAIA release: `gaia-v0.8.0`
- GAIA main SHA: `98ed66df5bd2cbd34887bdfc65e53d590c493cbe`
- Branch: `planning/gaia-v0.9-b4-work-package-builder`

## What v0.9 Is For

- understand approved project state;
- compare snapshots and detect meaningful change;
- surface drift, blockers, stale evidence, and release-state gaps;
- recommend the next best work deterministically;
- prepare human-reviewable work packages and Codex prompts;
- preserve explicit human approval before execution.

## What v0.9 Is Not For

- automatic code writing;
- automatic repository changes;
- automatic Codex invocation;
- autonomous execution;
- weakening the Dashboard read-only boundary;
- changing MicroGrow ownership.
