# GAIA v0.9 Acceptance Criteria

- A portfolio model exists for multiple approved repositories.
- Snapshot comparison surfaces meaningful change and drift.
- Recommendations are deterministic and explainable.
- Work packages are human-reviewable and revisioned.
- Approval states never execute work automatically.
- The Control Centre can prepare but not auto-run Codex.
- The Dashboard remains read-only.
- MicroGrow remains read-only unless a separate future decision explicitly changes that.
- Compatibility with released v0.8 Dashboard integration is preserved.
- Documentation reflects the v0.9 planning package and the v0.8 release baseline accurately.
