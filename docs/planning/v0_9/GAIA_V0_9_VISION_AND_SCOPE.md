# GAIA v0.9 Vision and Scope

## Vision

GAIA v0.9 turns GAIA into a practical local-first project officer that can inspect approved work, explain what changed, recommend the next best work, and prepare human-reviewable work packages.

## In Scope

- approved project portfolio intelligence;
- project health and release-state summaries;
- branch, working-tree, test, dependency, and documentation state;
- change, drift, and stale-evidence detection;
- deterministic prioritisation with explicit reasons;
- human-reviewable work-package generation;
- Codex prompt drafting without automatic execution;
- approval, handoff, completion, and provenance records;
- Control Centre workflow surfaces for review and preparation;
- read-only Dashboard summaries of status and recommendations.

## Out of Scope

- autonomous code writing;
- automatic branch creation or switching;
- commits, pushes, merges, or releases;
- direct Dashboard write capabilities;
- MicroGrow writes;
- cloud-only dependency on external models;
- automatic model downloads;
- hardware control.

## Product Shape

GAIA should feel like:

- a deterministic project officer that can explain what it sees;
- a planning assistant that prepares complete handoff packages;
- a review system that always waits for explicit approval before execution.
