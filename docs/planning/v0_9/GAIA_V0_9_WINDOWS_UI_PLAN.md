# GAIA v0.9 Windows UI Plan

## Target Experience

The GAIA Control Centre should include:

- Portfolio Overview;
- Project Health;
- Change Intelligence;
- Recommended Work;
- Work Queue;
- Work Package Builder;
- Evidence Viewer;
- Approval Review;
- Codex Prompt Preview;
- Execution Handoff;
- Completion Evidence;
- Trust Centre.

## UI States

- empty;
- loading;
- stale;
- blocked;
- degraded;
- read-only;
- ready for approval.

## Accessibility

- clear keyboard navigation;
- readable status copy;
- obvious provenance and freshness labels;
- safe recovery actions instead of hidden automation.
