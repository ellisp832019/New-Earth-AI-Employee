# GAIA v0.9 Dashboard Read-Only Plan

## Goal

Keep the New Earth Dashboard read-only while exposing useful planning summaries.

## Future Summary Surfaces

- portfolio health;
- highest-priority recommendations;
- blocked projects;
- pending approvals;
- stale evidence;
- recent completed work;
- trust alerts.

## Hard Boundaries

- no execution controls;
- no approval controls;
- no signing controls;
- no rollback controls;
- no retention controls;
- no direct database access.

## Integration Shape

The Dashboard should continue to consume official GAIA packages and a thin adapter only.
