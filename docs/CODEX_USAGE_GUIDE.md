# How to Use the Codex Prompt

1. Extract the ZIP to `D:\Dev\Projects\New-Earth-AI-Employee`.
2. Open that folder in VS Code.
3. Open the Codex panel while the repository root is the active workspace.
4. Open `CODEX_MASTER_PROMPT.md`.
5. Copy everything beneath the heading into Codex.
6. Let Codex inspect and validate the existing package.
7. Review its final report, especially tests and the MicroGrow pre/post Git proof.
8. Do not approve a push unless you intend to publish the repository.

The prompt deliberately keeps this package at GAIA v0.1. Model integration and the Windows desktop app belong in later controlled work packages.
