# Work Package and Validation Impact

## Work Packages

Existing work packages are inspected read-only.

Impact is reported when:

- the work package belongs to an affected project; or
- canonical evidence overlap can be proven from the work package record.

If linkage is insufficient, the result reports unknown rather than guessing.

## Validation References

Validation references are drawn only from canonical contract data, such as:

- test commands;
- build commands;
- documentation roots;
- release process references.

No declared command is executed automatically.

## Unknown Metadata

If a project exposes no canonical validation metadata, the result reports insufficient test metadata instead of fabricating checks.
