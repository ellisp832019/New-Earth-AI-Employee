# Navigation and Information Architecture

## Top-Level Shell

The Windows Control Centre keeps the existing top-level navigation and adds one new destination:

- Project Officer;
- Programme Intelligence.

## Internal Programme Navigation

Programme Intelligence uses a secondary navigation rail with:

- Overview;
- Architecture;
- Dependencies;
- Impact;
- Change Proposals;
- Roadmap;
- Release Trains;
- Programme Packages;
- Decisions;
- Evidence.

## Information Flow

- the backend returns one canonical workspace payload;
- the screen renders that payload into grouped review surfaces;
- selection is local to the workspace page;
- refresh is explicit and read only.

## Usability Notes

- no top-level rail explosion;
- no hidden execution buttons;
- no modal approval shortcut;
- no separate application window.
