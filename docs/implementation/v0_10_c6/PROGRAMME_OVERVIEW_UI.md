# Programme Overview UI

## Purpose

Provide a high-level operator summary of the programme state.

## Displayed Data

- project count;
- health status counts;
- change severity counts;
- recommendation state counts;
- roadmap state counts;
- release-train readiness counts;
- package-state counts;
- stale-evidence project list;
- trust alert count;
- provenance manifest count.

## Behaviour

- read only;
- refreshable;
- based on backend values only;
- no synthetic health scoring in Dart.
