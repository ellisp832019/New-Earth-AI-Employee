# Release Train UI

## Purpose

Let an operator review release coordination without publishing anything.

## Displayed Data

- train ID;
- objective;
- participating projects;
- required versions;
- dependency order;
- compatibility constraints;
- blocking evidence;
- required tests;
- rollback relationships;
- release readiness;
- human approval state;
- fingerprint;
- freshness and trust.

## Interaction Rule

- no release button;
- no tag creation;
- no deployment;
- no auto-merge.
