# Cross-Project Evidence UI

## Purpose

Surface provenance and evidence across programme-level artefacts.

## Displayed Data

- provenance manifests;
- capability payload;
- selected-project health evidence;
- selected-project recommendations;
- selected-project work packages;
- selected-project dependencies;
- selected-project dependents;
- repository and SHA references when available from backend payloads.

## Behaviour

- stale evidence stays visible;
- unknown evidence stays visible;
- trust state is rendered, not inferred.
