# Impact and Roadmap UI

## Impact Analysis

The impact page shows canonical change-impact analyses derived from backend recommendations:

- proposal identity;
- origin project;
- impact fingerprint;
- risk;
- freshness;
- trust;
- affected entities;
- affected projects;
- affected contracts;
- affected releases;
- affected work packages;
- validation references;
- refresh requirements;
- sequencing constraints;
- unknown findings.

## Change Proposals

The change-proposal page shows:

- recommendation identity;
- revision;
- title and summary;
- recommendation type;
- lifecycle state;
- priority;
- blocker and evidence context.

## Roadmap

The roadmap page shows:

- roadmap state groups;
- rank;
- source type;
- project;
- blockers and reasons when present.

## Boundary

The frontend does not recalculate impact, ranking, or priority.
