# Recommendation and Blocker Summary

The dashboard shows a bounded, backend-ranked recommendation list and a blocked-project summary.

## Recommendations

- preserve backend order
- show priority tier
- show deterministic score
- show project and title
- show a short rationale
- show freshness and blocked state

## Blocked projects

- show the blocked project or work-stream summary
- show blocker reason where available
- show recommendation/package counts where available
- keep the state read-only

## Boundary

The dashboard does not re-rank, re-score, or infer blocker state independently.
