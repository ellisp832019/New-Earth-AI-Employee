# Codex Prompt Review Boundary

B5 treats the generated Codex prompt as reviewable evidence, not executable content.

## Required UI text

- DO NOT EXECUTE AUTOMATICALLY
- HUMAN REVIEW REQUIRED

## Allowed action

- copy the exact prompt to the clipboard

## Disallowed actions

- launch Codex;
- open a shell;
- spawn a terminal;
- execute a process;
- paste the prompt anywhere automatically.
