# Accessibility and Windows Layout

The B5 workspace follows the existing calm engineering style and must remain readable on common Windows desktop sizes.

## Layout expectations

- 1280x720;
- 1366x768;
- 1600x900;
- 1920x1080.

## Accessibility expectations

- keyboard-safe controls;
- visible focus states;
- accessible labels and tooltips;
- no colour-only meaning;
- no obvious overflow in standard window sizes;
- status copy that clearly distinguishes healthy, blocked, stale, and unknown states.
