# Navigation and Information Architecture

The B5 workspace keeps the existing GAIA shell and adds a dedicated Project Officer area.

## Primary navigation

- Home;
- Projects;
- Project Officer;
- Ask GAIA;
- Evidence;
- Snapshots;
- Reports;
- Agent Runs;
- Tasks;
- Drafts;
- Approvals;
- Permissions;
- Action Centre;
- Receipts;
- Trust Centre;
- Embedded Workspace;
- Integration;
- Daily Brief;
- VS Code Ops;
- Audit;
- Settings;
- About.

## Project Officer information flow

- Portfolio summarizes all enabled projects.
- Project Health shows the latest snapshot, reason codes, provenance, and prior snapshots.
- Change Intelligence surfaces B2 findings with filters.
- Recommendations expose deterministic ranking, blockers, and scoring breakdowns.
- Work Packages show the revision history, prompt, approval history, handoff history, and provenance.
- Evidence panels reuse the same structured metadata across the workspace.
