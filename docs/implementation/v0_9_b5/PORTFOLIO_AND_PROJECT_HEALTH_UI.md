# Portfolio and Project Health UI

The portfolio view is the top-level entry to the B5 planning workflow.

## Portfolio fields

- project display name and project ID;
- current health state;
- latest health snapshot timestamp;
- current branch and short commit SHA;
- clean or dirty working tree state;
- ahead/behind status where available;
- recent meaningful change state;
- active and blocked recommendation counts;
- open work-package count;
- stale-evidence indicator.

## Health detail

- latest health snapshot;
- reason codes and explanations;
- evidence freshness;
- Git state;
- important paths;
- provenance and fingerprint visibility;
- prior snapshot history.

## Safety note

Unknown health must remain visibly distinct from healthy state.
