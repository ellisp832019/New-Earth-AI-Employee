# Work Package Review UI

The work-package review experience exposes the complete B4 package state without executing it.

## Detail sections

- overview;
- evidence;
- scope;
- non-goals;
- expected files;
- security boundaries;
- risks;
- backup requirements;
- implementation stages;
- validation commands;
- acceptance criteria;
- rollback plan;
- generated prompt;
- revision history;
- approval history;
- handoff history;
- provenance.

## Review boundary

- the exact approved revision stays visible;
- stale and expired packages are visibly blocked;
- the generated prompt can be copied but not executed by the app.
