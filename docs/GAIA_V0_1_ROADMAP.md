# GAIA Roadmap

## v0.1 — Evidence foundation

Included in this package:

- project registry;
- read-only Git inspection;
- safe document scanning;
- local indexing and search;
- snapshots;
- foundation reports;
- audit events;
- CLI and API.

## v0.2 — Local intelligence

Planned:

- Ollama provider abstraction;
- retrieval-grounded answers;
- evidence citations to local files;
- structured project-state analysis;
- feature classification: complete, partial, experimental, planned and deprecated;
- Codex prompt generator;
- evaluation dataset and hallucination checks.

## v0.3 — Desktop control app

Planned:

- Flutter Windows interface;
- project home;
- Ask GAIA;
- reports;
- task centre;
- audit viewer;
- model and privacy settings.

## v0.4 — Approval-controlled drafting

Planned:

- proposed file drafts;
- exact diffs;
- single-action approval tokens;
- approved document creation;
- rollback and validation.

## v1.0 — Organisation-wide operations employee

Planned only after hardening:

- multiple New Earth projects;
- calendar and meeting preparation;
- email drafting;
- engineering workflows;
- cross-project dependencies and version planning.

Physical equipment control, payments and safety-limit changes remain outside GAIA’s autonomous authority.
