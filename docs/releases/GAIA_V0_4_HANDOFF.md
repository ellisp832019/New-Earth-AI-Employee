# GAIA v0.4 Handoff

## Planning Goal

GAIA v0.4 should focus on controlled workflows and the first reusable integration foundation for the New Earth Dashboard.

## Candidate Themes

- Formal task records.
- Approval requests.
- Diff previews.
- Controlled document drafting.
- Approved local writes within the GAIA repository.
- Permission manifests.
- Reusable API contracts.
- New Earth Dashboard embedded GAIA module planning.
- Shared Flutter package planning.
- Daily operational briefs.
- Scheduled local workflows.
- Richer project-control intelligence.

## Boundaries

- No uncontrolled external-project writes.
- No direct MicroGrow control.
- No automatic Codex execution.
- No autonomous Git operations.
- No duplicated New Earth Dashboard AI backend.
- No direct database sharing between applications.
- No full New Earth Dashboard integration until the API and package contract is accepted.

## Handoff Note

v0.4 should extend GAIA workflows without weakening the read-only safety model established in v0.3.
