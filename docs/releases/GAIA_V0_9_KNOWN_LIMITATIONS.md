# GAIA v0.9 Known Limitations

- GAIA remains local-first and depends on a live backend for live state.
- Evidence freshness depends on the most recently captured project state.
- External repository state can change after evidence capture.
- Human review is required before approval and handoff.
- Generated Codex prompts are review material only and are not executed automatically.
- Target-repository operations remain manual.
- The embedded Dashboard is read-only.
- Hardware control is outside the v0.9 Project Officer scope.
- Cloud fallback is not provided by default.

## Release Boundary

These limitations are expected operating boundaries, not unresolved release blockers.
