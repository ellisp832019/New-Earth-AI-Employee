# Source / Interpretation Evidence

GAIA stores NEOS source facts separately from GAIA interpretation.

## Source Facts

- `finding_id`
- `rule_id`
- `severity`
- `canonical_owner`
- `system_id` / `project_id`
- `declared_state`
- `observed_state`
- `snapshot_id`
- `evidence`
- `governance_version`
- `neos_version`

## GAIA Interpretation

- explanation
- priority
- recommended next actions
- review questions
- programme context
- work-package preview

## Boundary Proof

The work-package preview is draft-only and `auto_execute` is false.
