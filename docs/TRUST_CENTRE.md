# Trust Centre

The Windows Trust Centre exposes operational trust state in plain language.

## It shows

- backend ownership
- compatibility
- capability status
- receipt-chain state
- review-package verification
- action-template catalogue
- retention posture

## It must not do

- it must not label hash-only receipts as signed;
- it must not hide unavailable or incompatible states;
- it must not execute output actions on behalf of the embedded dashboard.
