# Compatibility and Capabilities

GAIA v0.6 distinguishes between compatibility and capability support.

## Compatibility states

- compatible
- compatible_with_warnings
- client_too_old
- backend_too_old
- contract_mismatch
- unavailable
- timeout
- malformed_response

## Capability support

Capabilities are reported by the backend and used to gate UI features.

Examples:

- project summaries
- task proposals
- draft creation
- approvals
- daily briefs
- action summaries
- receipt verification
- offline packages
- retention policies

Product version alone must not be treated as proof of capability.
