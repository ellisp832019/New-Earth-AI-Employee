# Start Here

GAIA v0.1 is a safe project-inspection foundation, not yet a conversational autonomous employee.

## First use

1. Extract the repository to `D:\Dev\Projects\New-Earth-AI-Employee`.
2. Confirm MicroGrow exists at `D:\Dev\Projects\MicroGrow V1` or edit `config/projects.yaml`.
3. Run `scripts\setup_windows.ps1`.
4. Run `scripts\run_tests.ps1`.
5. Run `scripts\first_run.ps1`.
6. Read `data\reports\MICROGROW_FOUNDATION_REPORT.md`.
7. Start the API with `scripts\start_api.ps1` and open its `/docs` page.
