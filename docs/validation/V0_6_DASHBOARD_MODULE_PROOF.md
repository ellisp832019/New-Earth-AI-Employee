# GAIA v0.6 Dashboard Module Proof

The reusable dashboard module is provided in `packages/gaia_dashboard_module`.

## What it demonstrates

- Loopback-first integration through `gaia_integration_client`.
- Compatibility and degraded-mode display.
- Project, task, approval, receipt, and trust summaries.
- Read-mostly trust messaging for the embedded boundary.

## Example host

The reference host lives in `examples/gaia_dashboard_host`.

It demonstrates:

- responsive layout;
- light and dark themes;
- keyboard-friendly tab navigation;
- no dependency on the separate New Earth Dashboard repository.
